Privacy Policy

NK_Zynvero Uploader — last updated 28 September 2026

This is a personal tool used only by the owner of the YouTube channel NK_Zynvero to upload that channel's own videos.

What data it uses

With the owner's permission, it uses Google's YouTube Data API to upload videos to, and read basic details of, the owner's own YouTube channel. It does not access any other user's data.

Storage and sharing

The Google sign-in token is stored only on the owner's own computer. No data is sold, shared with third parties, or sent anywhere other than Google's YouTube services.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
